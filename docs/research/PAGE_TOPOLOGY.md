# Page Topology

1. Sticky header: brand, primary navigation, desktop search, mobile menu toggle.
2. Full-width hero: backdrop layer, dual dark overlays, media copy, metadata, details action.
3. Intro/share strip: compact page statement and sharing controls.
4. Trending movies: horizontally emphasized first content section.
5. Popular movies: responsive poster grid.
6. Popular TV series: responsive poster grid.
7. Genre discovery band: compact genre links.
8. Footer: brand statement, navigation columns, TMDB attribution, copyright.

The page uses the document scroll container. Header is sticky at z-index 50. Hero overlays remain local to the section. No nested scrolling or scroll snap is used.
