# Interaction Patterns

- Navigation links use a 160ms color transition and visible keyboard focus ring.
- Mobile navigation is a click-driven full-viewport disclosure with body scroll lock.
- Hero slides crossfade every seven seconds and can be selected through accessible tab buttons.
- Poster hover/focus darkens and scales the image while revealing a centered action icon.
- Search uses native GET forms, keeping results linkable and cacheable.
- The watch action opens a native modal dialog that explicitly states playback is unavailable.
- `prefers-reduced-motion` disables meaningful animation duration and automatic visual movement.
